# matveylutsenko.com

Personal CV website for Matvey Lutsenko: a single static page, hosted on Cloudflare.

## Structure

- `index.html` – the whole site (HTML, CSS and JS in one file)
- `headshot.jpg` – profile photo used in the nav
- `Matvey_Lutsenko_CV_2026.pdf` – CV behind the "Download CV" buttons

## Deploying

The repo is connected to Cloudflare, so every push to `main` deploys automatically.
No build step: the site is served straight from the repo root.
